# ScanEdit Pro — Mac app downloads

ScanEdit Pro lets you edit the text of scanned PDFs and scanned documents. OCR in English, Italian,
Spanish and French runs on your device: your files are never uploaded.

This repository only hosts the installers of the ScanEdit Pro Mac app (Apple Silicon, M1 or later).
It contains no source code.

The app requires a ScanEdit Pro Mac license. Buy one at https://www.scaneditpro.com, then enter it
in the app with 🔑 PRO License.
